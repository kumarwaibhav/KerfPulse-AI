# Acquisition objective audit and next experiment

Independent source/artifact review found the acquisition experiment optimizes an immediate per-cut inspection loss, while the benchmark permanently scores the first drafted inspection. That proxy omits the consequence of an early irreversible alarm and the value of waiting. Increasing network capacity cannot fix this objective mismatch by itself.

Only five tools (2/4/6/8/9) satisfy exact outer training-recipe support, covering 375 cuts. Their current first slots are 33/21/21/102/69 against damage 50/41/30/116/150: every first inspection is premature. Later observed timely opportunities exist for every supported tool (2:45/48;4:36/39;6:27;8:111/114;9:147). Eight other observed tools abstain entirely; tool11 has no pre-damage opportunity. Thus 0/14 includes 0/5 timely supported lives, eight domain abstentions and one no-opportunity life.

All 29 learned acquisitions occur on tool9; learned first slot66 is 84 cuts premature. Full fusion also fails to make any supported outcome timely. Current-only matches outcomes with zero optional acquisitions.

The runner continues acquisition after first_slot becomes fixed. Its acquisition counts describe full recorded-life monitoring, not pre-intervention savings. Candidate ceil(n*.25) allows first-cut acquisition; older floor(n/4) requirement does not. These budgets are distinct and their results cannot be merged. Candidate threshold .05/fixed C=.01/T=1 and support filtering also differ from nested calibrated baseline threshold .5.

## Proposed next exploratory protocol — not run

Freeze a new first-stop experiment before execution. Keep original artifacts unchanged. Instrument actionable scores, gate gains, support, quota and acquisitions before/after first fixation. Enforce inner-fold recipe support consistently with outer abstention.

Use training-only component-disjoint cross-fitted trajectories and terminal first-inspection loss, with a frozen continuation policy. Illustrative loss may be inspection_exists +20*not_timely +.1*acquisitions_before_first_decision. Stop scored acquisition after first recommendation. Tune only a small predeclared threshold grid inside development groups, with equal total tool weight. Compare current-only, periodic, risk-margin and terminal-regret gate using identical floor prefix quota; keep full fusion as resource reference. Report actual spending, all outcomes, domain coverage and paired group uncertainty.

These scales are illustrative, not plant financial estimates. Outer outcomes already informed this diagnosis, so another experiment on this dataset remains exploratory. Independent machine/cohort or prospective frozen outcomes are required for confirmation and promotion. Sequential acquisition has prior art; this diagnostic improves objective alignment rather than establishing novelty itself. [ICML 2024 Acquisition Conditioned Oracle](https://proceedings.mlr.press/v235/valancius24a.html).

No new training was performed for this audit. Evidence came from pinned measurements, saved reports and source inspection. Existing negative findings are retained.
