# KerfPulse AI implementation checkpoints

Brand: KerfPulse AI
Tagline: Precision in every signal. Certainty in every shift.

1. Verify environment, pinned data checksum and source chronology. Save machine inventory and dataset audit.
2. Train CPU baselines first. Leave complete cutters out. Fit preprocessing inside each fold. Exclude damage-cycle predictors. Save per-cut out-of-fold predictions, tool-level metrics and immutable model provenance. Check sample/workpiece overlap and recipe support.
3. Implement budgeted selective release and inspection-slot benchmark. Tune thresholds using training tools only. Compare current, periodic, decision and fused policies. Report unsuccessful hypotheses.
4. Build persisted MQTT ingestion, session-isolated API and work orders.
5. Apply saved warm-industrial dual-theme design with graphical evidence and accessible controls.
6. Read all routes and features, complete security audit, then run browser feature tests. Save severity-ranked findings and test evidence.
7. Package Compose, terminal commands, data attribution and deployment instructions. Verify actual deployments before claiming hosted availability.

Phase reports must distinguish completed verification from pending work. Source signal fixtures must always come from verified benchmark files. GPU use depends on measured model benefit and available drivers.
